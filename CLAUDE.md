# duohuygo-xiangqi

Duolingo-style web app for learning Chinese chess (Xiangqi). Static site only: no backend in this phase.
Must work in desktop and phone browsers and as an installable, offline-capable PWA.

## Commands

| Task | Command |
| --- | --- |
| Install deps | `npm install` |
| Dev server (http://localhost:5173) | `npm run dev` |
| Production build (type-check + bundle to `dist/`) | `npm run build` |
| Preview the production build (service worker active) | `npm run preview` |
| Run all tests once | `npm test` |
| Tests in watch mode | `npm run test:watch` |
| Run one test file | `npx vitest run src/engine/pieces.test.ts` |
| Lint (oxlint) | `npm run lint` |
| Type-check only | `npm run typecheck` |
| Regenerate placeholder PWA icons | `npm run icons` |

`npm run build`, `npm test` and `npm run lint` must pass before committing.

## Stack

Vite + React + TypeScript, Tailwind CSS v4 (via `@tailwindcss/vite`, no config file), Vitest,
vite-plugin-pwa (manifest + Workbox service worker, `registerType: 'autoUpdate'`), oxlint.
`base: './'` in `vite.config.ts` so the build can be served from any sub-path on static hosting.

## Engine conventions

- Square index = `rank * 9 + file`. Files `a..i` left to right from Red's side; ranks `0..9` with
  rank 0 = Red's back rank. Square names are ICCS style: Red general starts on `e0`, Black on `e9`.
- FEN lists rank 9 first. Uppercase = Red. Letters `k a b n r c p` (`e`/`h` accepted as aliases).
  Side to move `w` (or `r`) = Red, `b` = Black.
- Positions are immutable from the outside: `makeMove` returns a new `Position`.
- The flying-general rule is handled inside `isGeneralAttacked` (the enemy general "attacks" along an open file).
- Stalemate is a loss for the side to move (`gameStatus` returns `{ kind: 'stalemate', winner }`).
- Not implemented yet: perpetual check/chase rules, repetition, move-count draws.
- Perft from the start position must equal 44 / 1,920 / 79,666 / 3,290,240 (depths 1–4).
